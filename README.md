# Книжная читалка (bookreader-helper)

Локальное приложение для чтения английских книг целиком: построчный перевод на русский с переводом над каждым словом,
личный словарь слов и фраз, повторение карточками и озвучка. Всё работает на этом компьютере и бесплатно:
перевод делает Claude Code в headless-режиме по подписке (`claude -p`), запасной вариант — локальный Ollama,
озвучка — Kokoro-82M на CPU. Платных API и API-ключей нет.

## Запуск

```bash
npm install
npm start
```

Откройте http://127.0.0.1:5180. Сервер слушает только 127.0.0.1.

На рабочем столе есть ярлык «Книжная читалка» (`scripts/start.cmd`): собирает интерфейс, запускает сервер в свёрнутом
окне и открывает читалку в браузере; если сервер уже запущен — просто открывает читалку. Закрытие окна сервера его останавливает.

- Данные (книги, база, аудио, модели) — в `D:\bookreader-data` (другая папка — переменная `BOOKREADER_DATA`).
- Перевод через Claude Code требует входа CLI по подписке (один раз): `powershell -ExecutionPolicy Bypass -File scriptsclaude-login.ps1`
  — это `claude auth login` с очищенным окружением (без переменных Claude Desktop и ANTHROPIC_*).
- Для разработки: `npm run dev` (Vite на 5173 с прокси к серверу на 5180). Тесты: `npm test`.

## Как пользоваться

1. **Библиотека → «Добавить книгу»** (EPUB, FB2, TXT). Книга разбирается на главы, абзацы и предложения
   и ставится в фоновую очередь перевода. Читать можно сразу: переведённые главы появляются по мере готовности,
   глава, которую вы открыли, переводится в первую очередь.
2. **Читалка.** Слева английское предложение с переводом над каждым словом, справа полный перевод.
   - `H` — режим подсказок: видны / по наведению (по тапу на сенсорном экране) / скрыты.
   - `T` — показать/скрыть колонку перевода; в списке рядом есть режим «по клику» (перевод по клику на номер).
   - Клик по слову — карточка: перевод в контексте, словарное значение, лемма, часть речи, озвучка, «Запомнить».
   - Выделение нескольких слов — перевод фрагмента в контексте (Ollama → переводчик Chrome → Claude), «Запомнить» в «Фразы».
   - `A` — аудиокнига: чтение главы вслух с подсветкой и автопрокруткой; `Shift+↑/↓` — по предложениям; `Alt+←/→` — главы.
   - ☰ — оглавление с прогрессом по главам и закладки; 🔖 — закладка. Позиция чтения запоминается.
3. **Слова / Фразы** — поиск, фильтр по книге, сортировка, озвучка, переход к месту в книге, удаление, экспорт в JSON.
4. **Повторение** — слова, фразы или всё вместе. Выучено после верных ответов в 3 разных дня.

## Перевод

Адаптер с одним интерфейсом `glossBatch(sentences) → [{ full, tokens: [{ en, ctx, lemma, base, pos }] }]`:

- **claude-code** (по умолчанию): `claude -p --model sonnet --output-format json --no-session-persistence
  --system-prompt-file … --tools "" --strict-mcp-config …`. Без `--bare` (он отключает вход по подписке);
  из окружения дочернего процесса удаляются `ANTHROPIC_*` и переменные чужого сеанса Claude Code.
  Thinking выключен (`MAX_THINKING_TOKENS=0`): с ним та же пачка шла в 3,5 раза дольше и тратила в 4 раза больше токенов.
  Пачка ограничена 12 предложениями и 250 словами; ответ читается потоком, процесс снимается только после 3 минут тишины.
  При лимите подписки очередь встаёт на паузу и продолжает сама после сброса.
- **ollama**: локальная модель (по умолчанию `qwen3:8b`, быстрее — `gemma3:4b`), structured output по JSON-схеме,
  thinking выключен, число потоков ограничено. Ollama лежит в `D:\bookreader-data\ollama`, модели —
  в `D:\bookreader-data\models\ollama`; сервер приложения сам запускает `ollama serve`. В настройках —
  загрузка модели и замер скорости на 5 предложениях книги с оценкой времени на всю книгу.
- **stub** — без перевода (леммы и части речи локально), для проверки интерфейса.

Каждый ответ проверяется: валидный JSON, токены посимвольно восстанавливают предложение. Ответ сопоставляется
с предложениями по выравниванию, а не по позиции; пропущенные дозапрашиваются, обрезанная пачка делится пополам.
Если модель дважды нарушила разбивку, токены чинятся так, чтобы строка всё равно совпадала с оригиналом.
Кэш по хэшу предложения + провайдеру + модели. Прогресс хранится по предложениям — после перезапуска очередь
продолжает с места.

## Озвучка

Kokoro-82M (`kokoro-js`, ONNX, CPU) в отдельном потоке с ограничением числа потоков. Замер на Ryzen 5 5600H:
fp32 — 1,3–1,7× быстрее реального времени (4 потока), q8 — 0,5× (медленнее fp32 на этом CPU), поэтому по
умолчанию fp32. Аудио — файл на предложение: Opus через ffmpeg, если он есть в PATH, иначе MP3 (lamejs).
Озвучка глав идёт в фоне после перевода (текущая глава первой) и ждёт, пока перевод через Ollama занимает CPU.
Слова и фразы озвучиваются на лету с кэшем.

## Структура

```
server/index.js            API, SSE, раздача собранного фронтенда
server/db.js               SQLite (better-sqlite3): схема, миграции, настройки
server/books.js            книги, главы, предложения, позиция, закладки
server/importers/          EPUB, FB2, TXT → главы → абзацы → предложения
server/queue/translate.js  фоновая очередь перевода
server/providers/          claude-code, ollama, stub, промт
server/gloss.js            сопоставление ответа по выравниванию, починка токенов
server/vocab.js            слова, фразы, примеры, повторение
server/selection.js        перевод выделения
server/tts/                Kokoro в потоке, очередь озвучки, кэш
server/ollama-manager.js   запуск Ollama, загрузка моделей, замер скорости
shared/                    segment.js, align.js, gloss-local.js (общие для сервера и браузера)
web/                       фронтенд (Vite + React)
```
